## Impeccable — ideas adapted

`references/review-rubric.md` and the severity scale in `SKILL.md` adapt ideas from
Impeccable (https://github.com/pbakaus/impeccable, v4.8.0, commit
`687bc381bc9091bf252c0a05303640561014a425`, `skill/reference/audit.md` and
`skill/reference/craft-floor.md`), by Paul Bakaus (`package.json` author; the repository
states no separate copyright line), licensed under the Apache
License, Version 2.0 (https://www.apache.org/licenses/LICENSE-2.0).

Changes: the audit dimensions, P0–P3 severity labels and render-verification checks
were rewritten in this hub's words and merged with UX, reuse and architecture checks;
scoring bands, command routing, the detector, sub-agent orchestration and the binary
launcher were not taken. No Impeccable file is copied.
